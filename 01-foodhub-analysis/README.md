# FoodHub Data Analysis

## 📊 Project Overview

This project involves analyzing food delivery order data for FoodHub, a food aggregator company. The analysis provides actionable insights to improve business operations, customer satisfaction, and revenue optimization.

## 🎯 Business Problem

FoodHub connects customers with restaurants through a mobile app. The company needs to understand:
- Customer ordering patterns and behavior
- Restaurant performance metrics
- Delivery time analysis
- Revenue drivers and optimization opportunities
- Factors affecting customer ratings

## 📁 Dataset

**File:** `foodhub_order.csv`

### Dataset Description
- **Source**: FoodHub order database
- **Records**: Multiple food delivery orders
- **Features**: Order ID, Customer ID, Restaurant details, Cuisine type, Cost, Day of week, Rating, Delivery time, etc.

### Key Variables
- `order_id`: Unique identifier for each order
- `customer_id`: Unique customer identifier
- `restaurant_name`: Name of the restaurant
- `cuisine_type`: Type of cuisine ordered
- `cost_of_the_order`: Order value
- `day_of_the_week`: Day when order was placed
- `rating`: Customer rating (if provided)
- `food_preparation_time`: Time taken by restaurant
- `delivery_time`: Time taken for delivery
